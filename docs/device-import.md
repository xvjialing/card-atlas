# 设备素材导入

## 产品与摄影工作流

CardAtlas 分为“设备导入”和“素材分析”两个入口。前者把摄影设备原片带回电脑，后者分析存储卡、已挂载磁盘或本地素材。设备品牌不决定归档与任务模型。业务依据是本次用户要求：通用设备素材导入，先整合 osmo-bridge 的 Action 6 连接和导入，兼顾产品流程和摄影使用。

当前无线适配为 macOS DJI Osmo Action 6，兼容性标记为“待实机验证”。DJI 无人机、索尼等尚未实现无线适配；已挂载的存储仍可通过素材分析使用。

1. **连接设备**：蓝牙发现与配对 → 相机屏幕确认 → 扫描并选择真实热点 → 明确确认切换 Wi-Fi → 读取内置存储与 SD 卡。也可先通过系统 Wi-Fi 菜单加入热点再接续。
2. **挑选原片**：真实缩略图、照片/视频预览、拍摄日期、存储位置和时长；按类型、日期闭区间、存储、文件名筛选。默认网格，也可切换列表或按拍摄日分组的时间线。三种视图每页 30 项，共用选择；时间线“全选当天”覆盖当前筛选条件下所有分页，并显示半选状态。类型与存储筛选直接展示为按钮组，提示筛选外的已选素材。
3. **确认归档**：先选择目标文件夹，查看数量、目标和路径示例，再开始导入。保留原始字节、文件名和拍摄时间，不转码、不删除设备文件。
4. **检查结果**：提交后自动弹出任务窗口，区分下载、生成本地指纹、最终保存、完成；支持暂停全部、恢复当前设备的未完成任务、单项重试、定位文件，并打开导入目录继续素材分析。关闭窗口后后台继续，顶部“导入任务”可重开。记录不再堆在页面底部；弹窗区分本次导入与全部记录，使用后端规划的 taskIds 确保历史任务不影响本次进度。

| 策略 | 目录 | 用途 |
| --- | --- | --- |
| 按拍摄日期归档（默认） | `photo/YYYY/MM/DD/原文件名`、`video/YYYY/MM/DD/原文件名` | 与现有资料库一致 |
| 保留设备原目录 | `设备原目录/设备标识摘要/存储标识/原路径` | 保留机内层级，区分机身和存储介质 |

没有有效日期时放入 `日期未知`，不会拿导入当天冒充拍摄日期。Action 6 清单时间不带时区，按本机时区解释；EXIF 与视频内部元数据保持原样。清单容量可能受 32 位协议字段影响，界面显示估计值，下载以 HTTP 实际长度为准。

重名文件追加 `_001` 等编号，不覆盖已有文件。重复导入判断只适用于适配器、设备、素材身份、日期、长度、目标目录和目录策略一致的已有记录，不按文件名做内容去重。已有完成记录的目标文件丢失或长度变化时可以重新导入；同长度内容变化不能只凭记录识别。

## 扩展架构

```text
DeviceImportPage / DeviceConnectionDialog
  ↓ Wails 类型绑定
DeviceService：目录选择、文件定位、应用入口
  ↓
deviceimport.Manager：规划、重名编号、持久化、队列、恢复
  ↓ Provider 接口
devices/action6.Adapter：配对、热点、会话、清单标准化
  ↓
dji + dji/transfer + platform：设备协议与系统能力
```

`internal/deviceimport/types.go` 定义接口。`Descriptor` 表达类型、连接方式、平台可用性、兼容性和可筛选存储来源；`Session` 表达连接阶段、会话令牌和清单版本；`Media` 使用字符串存储标识，不依赖 DJI 的整数编号；`Task` 固化设备、素材快照、目标及相对路径。

新增设备时实现 `Provider` 并注册到 `NewManager`。品牌参数和原始清单字段在适配器内解释，通用队列不增加品牌判断。当前连接表单是 Action 6 专用表单；其他连接方式可使用自己的表单，复用素材列表与任务界面。预览路由当前只注册 Action 6，新增适配器需要注册受控预览处理器，前端仍只提交素材 ID 和会话令牌，不提交任意设备地址或路径。

首版只允许一个活动设备、串行下载。未虚构未来设备协议。通用队列测试使用名为 `future-camera` 的模拟适配器，验证品牌无关性。

## 数据与恢复

- 系统用户配置目录 `CardAtlas/devices/` 保存配对身份、导入记录和脱敏日志；`CARDATLAS_DEVICE_DATA` 仅供测试或独立配置使用。重启后未完成任务变为暂停，不自动切网或下载。
- 队列成功落盘后才开始下载。原记录损坏时阻止新导入，不覆盖原文件；保存失败保留界面告警。导入记录长期保留在本机、每页 10 项；本地分析导出记录仍为进程内最近 20 次。
- 密码提交后保存至 CardAtlas 独立的 macOS 钥匙串命名空间，不与 Osmo Bridge 混用。密码不进入状态、日志、URL、普通 JSON 或浏览器存储，可修改或忘记。
- 热点切换必须明确提交。认证失败保留蓝牙会话，允许重试或手动加入；只有主动取消、断开、退出才尝试恢复原网络，恢复失败明确提示。
- 续传核对设备、存储、路径、日期和清单长度；其他设备不能恢复旧任务。未通过蓝牙识别的手动会话不跨重连自动续传。
- `os.Root` 将目标操作限制在用户选择目录，拒绝危险名称、越界路径和非普通续传文件。发布目标不覆盖现有文件；不支持硬链接时采用独占创建、复制与读回哈希检查。
- 若发布文件后、队列落盘前断电，可能出现“文件已存在但任务未完成”。应用停止覆盖并保留错误，需要核对文件或更换目录重新选择，不擅自认定完整。
- 下载检查 HTTP 范围和长度，并生成本地 SHA-256 指纹。设备未提供源端哈希，不宣称源端哈希核验通过；预览不等于原片已保存。磁盘空间不足由实际写入报错，清单估计不能保证剩余空间足够。
- 无云上传、遥测、设备删除或格式化。保留迁入的日志脱敏、按天及容量滚动；本次不迁入日志设置页面。

## 验证与后续

Go 测试覆盖通用规划、碰撞、恢复、持久化失败、固定协议报文、UDP 模拟设备、HTTP 续传和预览。浏览器脚本 `frontend/tests/device-browser-check.mjs` 导出检查函数，接受 Playwright page、工程根目录及 `device-fixture.mjs` 文本，通过模块请求拦截注入模拟接口；不打包测试数据，不执行真实导入。

实机仍需覆盖首次系统权限、相机屏幕配对、实际热点认证、内置存储与 SD 卡、大于 4 GiB 视频、断网重连、外接盘实测和网络恢复。未来按设备能力扩展 RAW+JPEG 关联选择、分段视频与伴随文件、双份备份、源端哈希；当前不作已支持承诺。
